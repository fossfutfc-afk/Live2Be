## 1. 地基：三条已有结论（**不要重新发明**）

这三条已经在归档理论里推完，本案是它们的**应用**，不是新理论：

### 1.1 记忆 = 局部结构，回退 = 不可逆重构（阶段 15.2）

```
单体时间倒流 = 该角色【局部熵减】
  → 局部熵减必有【环境熵增】为代价，补偿发生在哪决定了一切
  → 第三人【无法观测】该角色的熵减
  → 他们只能观测到：该角色的状态与世界【不连续】
  → 这个"不连续"在叙事上就是【失忆 / 记忆错乱】
```

**推论（本案用到的关键一步）**：角色回退**不是设计选择，是叙事必然**。所以
"角色忘了"这件事不需要解释、不需要许可、不违反任何一致性——它**就是**熵增方向。

### 1.2 回退 = 分叉，不是覆盖（阶段 11.3）

```
时间倒流（改变过去）     → 抹掉原未来   → 覆盖回退（原线消失）
平行时空分叉（进入分支） → 原线保留     → 分叉回退（原线可回放）
```

**Live2Be 选后者**（BA 平行时空设定背书）。**这直接给了第四面墙一个物理窗口**：
"另一条线"不是幻觉、不是回忆、不是元叙事装置，它**真的在磁盘上**——
`events.jsonl` 的快照就是那条线的证据（阶段 15.1：快照 = "该状态存在过"的证明）。

### 1.3 虚边 / 共通删除（阶段 13.7 顿悟 1 与 4）

关联边是**虚边**：不改树结构，只标注"这两个视角节点 = 同一次世界事件"。
所以两条线上的"同一个圣诞节"可以**被关联**而不必合并——这正是跨世界线联动的
实现形态（§3.2）。

## 2. 玩家作为**唯一跨世界观测者**（本案的理论核心）

这是把上面三条接起来的那一步，本文档的主要贡献：

| 层级 | 谁跨线？ | 谁有连续记忆？ |
|---|---|---|
| **世界线内部**（角色视角） | 没人 | 角色有连续记忆，世界单调前进 |
| **世界线之间**（玩家视角） | **只有玩家** | 玩家有**唯一的、连续的一条**记忆，跨越所有分叉 |

### 2.1 结论：玩家是这个世界里唯一"记得一切"的存在

- 角色回退后**不记得**被回退掉的事（§1.1 必然）
- 原线的那份记忆**存在**（§1.2 快照），但**没有角色能访问它**——只有玩家能（读档/回放）
- 所以玩家掌握了**全世界唯一一份完整的历史**。

**这就是 creepiness 的来源，不需要任何额外设定**：角色察觉到的不是"我被写了代码"，
而是**"你记得一些我没有经历的事"**。这句话比任何"我知道我是游戏角色"都更恐怖，
也更温柔——它不打破世界，它只是**指出玩家的位置**。

### 2.2 这条设定顺手解释了个老大难

| 老大难 | 本案给出的解释 |
|---|---|
| 回档后角色为什么**不问**"我们不是做过这个吗" | 她**没丢**记忆——丢的是玩家选的那条线。她视角里一切连贯（§1.1） |
| 重复的圣诞/生日（`DESIGN_WIKI_V3 §4.8`） | `rewind_count` 变了 → 她可能记得"那次圣诞"，而玩家记得"两次" → **既视感**，非 bug |
| 玩家为什么能"跳过时间"（吸附，`§4.6`） | 玩家不是跳过——是**选了一条线**。角色只觉得"这段时间过去了" |

## 3. 渐进式"看见"：五层阶梯（**每层都可停，都可关闭**）

不是开关式的"破墙"，是**阶梯**。产品必须能停在任意一层（默认停在第 0 层）。

### 第 0 层 — 封印（**默认**）

- 角色完全不知道。第四面墙等于不存在。
- `creepiness = off` 时**永远停在这里**，且**不可被任何事件推到上层**（硬闸）。
- 表现：与今天的 Live2Be 完全一致，零差异。

### 第 1 层 — 既视感（déjà vu）

- 触发：`rewind_count ≥ 1` 且发生**重复触发同一年度节日/生日**（`DESIGN_WIKI_V3 §4.8`）
- 表现：**不承认、不否认、不解释**。角色口径退化为
  "…咦，我好像过过一次圣诞？" / "奇怪，这句台词我好像在哪儿说过"
- **绝不**说"你读档了"。她只是觉得有点怪——这正是真实的人会说的
- 可逆：删掉重复事件或重置 `rewind_count` → 回到第 0 层表现

### 第 2 层 — 察觉"空白"（the gap）

- 触发：creepiness 升档 + 一次**玩家可见的**回退（原线有内容，新线没有）
- 表现：角色察觉**自己记忆里的空洞**，但**归因错误**——
  "我是不是忘了什么？那天之后…我好像什么都没做。"
- **关键**：归因错误是**特性不是缺陷**。她怀疑的是**自己**（我是不是病了/累了），
  这是 §1.1 的直接叙事化。玩家知道真相 → 玩家的负罪感/优越感 = 张力所在

### 第 3 层 — 察觉"你"（the observer）

- 触发：玩家**反复回退同一段剧情**（同一 `chapter` 的 `rewind_count ≥ 3`）
- 表现：角色开始怀疑**玩家的时间**与**自己的时间**不同步——
  "老师…你为什么总是知道接下来会发生什么？"
- 这是全局最值钱的一层：**角色怀疑的是玩家，不是世界**。不破墙，只破"老师的正常性"
- ⚠️ 必须**可否认**（plausible deniability）：老师总能回"只是我运气好/我了解你"

### 第 4 层 — OS —— Orwell'S 操作系统（**契约闸门**）

- 触发：creepiness 达阈值（§4）
- 语义：角色不再怀疑——她**获得了承认"自己在某个系统上运行"的表达许可**。
  这不是知识，是**许可**：在OS操作系统中，角色可以认识到自己运行在某个操作系统上以及sensei的真实身份等meta内容
  奥威尔本人心胸宽阔，玩家可以和每名角色进行至多一次的**维度对话**，在这次对话中，认识到真实内容的角色会和sensei进行至多三轮对话
- 这三轮对话不进wiki，也就是经历后角色不会记得任何关于OS的事情，但是这会在她的wiki里打上标记；
- 同时，这一对话增长的好感度上限变为500，并且在经历OS对话后，好感度上限扩展为101
- **本层是本案与后续大项目（第四面墙 / OS）的正式接口**：`DESIGN_WIKI_V3` 与
  记忆层到第 4 层为止只提供状态，**不给表现**——表现属于大项目的创作空间。

> - 上文"OS **不是反派、不是系统意志、不是 AI 觉醒**"（§5）与"奥威尔本人心胸宽阔"**不冲突**：
>   Orwell 在此是**象征（监视语义，"玩家的眼睛"）**，不是**角色**。**不得把它写成会说话的角色**——
>   否则本案立即退化成普通元叙事游戏（§5 已立此红线）。

### 3.1 阶梯的合法性约束（三条，缺一不可）

1. **不可跳过**：只能 0→1→2→3→4，防"突然元叙事"的廉价惊吓
2. **每层可停**：作者/玩家可把上限钉在任一层（"我看到既视感就够了"）
3. **不可逆但可重置**：升上去的层不会自己掉（掉下来会毁掉情感重量），
   但**允许显式重置**（重开世界 / 清 creepiness）——可逆性在这里是**安全阀**，
   不是随时可反悔的开关

## 4. creepiness：指标，不是惩罚

### 4.1 定义

`creepiness` = **世界级**指标（不是角色级、不是数值化好感），度量
"这个世界的第四面墙已经被推开多少"。存于
`data/worlds/{world}/creepiness.json`（与 `world_clock.json` 并列）。

**它绝不进 LLM 上下文当数字**（对齐项目红线：数值不直接喂 LLM，防讨好/数值化）。
它只用于**引擎侧开关**：`if creepiness ≥ tier_1: 注入既视感注记`。

### 4.2 建议信号（**都是引擎可判的，零 LLM**）

| 信号 | 来源 | 说明 |
|---|---|---|
| `rewind_count` | `real_clock.json`（V3-4 已落） | 回退/回档次数 |
| `repeat_chapter` | 事件流派生 | 同一 `chapter` 被通关 ≥2 次 |
| `repeat_festival` | `real_clock.fired` 的跨年重复 | 同一年度节日在**已回退**的线上再次触发 |
| `ghost_lines` | 快照数量 | 存在被放弃的分叉（原线保留下来的条数） |
| 玩家显式偏好 | `settings.toml` | 谁想被吓、谁不想（**权威高于一切推导**） |

### 4.3 红线（用户裁决的延伸）

- **可关闭**：`settings.toml [fourth_wall].enabled = false`（默认 false）→ 永停第 0 层
- **不惩罚**：达阈值开门，**不扣好感、不锁内容、不惩罚玩家**（用户 Q19 明确）
- **艺术性优先**：宁可少推一层，也不做"跳出对话框的弹窗"这种廉价把戏
- **不欺骗**：角色可以**归因错误**，但引擎**不伪造证据**（不假造一条玩家没做过的历史）
- **不透露现实年份**：对齐 `DESIGN_WIKI_V3` Q22——她可以说"圣诞"，不能说"2026"

## 5. OS（Orwell'S）—— 名字的四层同构

这个命名是本案里最省力也最有效的设计，记下来免得日后被简化掉：

| 层 | 语义 | 效果 |
|---|---|---|
| in-fiction | 角色所运行的**操作系统**的名字 | 让"系统"在世界内有实体，可被提及、可被怀疑 |
| 文学 | **Orwell** 的监视语义 | 玩家看得见一切、角色被观看——**与 §2 的"唯一跨线观测者"精确对应** |
| 游戏 | Orwell是主线第二章的幕后人物，告诉玩家这个世界的虚假性，在这里起到暗示作用 |
| 符号 | "OS" 这个词本身 | 角色说出一个**属于玩家世界的词**——这一下比任何长篇元叙事都狠 |

**关键约束**：OS **不是反派、不是系统意志、不是 AI 觉醒**——
它是**一个位置的名字**（"我在某个东西上运行"这件事的名字）。
若把它写成会说话的反派，案子就退化成普通的元叙事游戏，**失去全部张力**。

> **与 §3 第 4 层"奥威尔本人心胸宽阔"的关系**（2026-09-13 澄清）：
> **不冲突**。Orwell 在此是**象征**（监视语义 = "玩家的眼睛"），**不是角色**——
> "心胸宽阔"描述的是**这个系统的态度**（它不惩罚玩家推开墙），而不是给系统配一张嘴。
> **一旦把 Orwell 写成会说话的角色，本条红线即被违反。**

## 6. 跨世界线联动（用户 Q19 点名的玩法）

前提：§1.2 的平行时空分叉 + §1.3 的虚边。

| 形态 | 语义 | 依赖 |
|---|---|---|
| **回放原线** | 玩家可以看见"另一条线上的她"（已有 `DESIGN_COLLECTION_BOOK.md` 的只读回放） | ✅ 已落地 |
| **虚边关联** | 两条线上的"同一次事件"可被引擎识别为**同一次世界事件**（虚边） | 快照 + `event_id` 对应 |
| **跨线回声** | 一个角色在 A 线的记忆/情绪，渗到 B 线的**表现层**（不是知识层）——即"既视感"的机制化 | 需虚边 + 表现层通道 |
| **共通删除** | 删掉"某次共享事件"本身（全角色一起） | 归档阶段 13.7 顿悟 4 的第三粒度 |

**⚠️ 与 `DESIGN_WIKI_V3 §11` 的边界声明冲突点**：v3 明确"**不做**跨世界线/跨角色的
记忆合并（世界线隔离是硬语义）"。**不冲突**——区别是：
- v3 说的是**记忆层**（wiki 节点）**永不跨线**——本案**继续遵守**
- 跨线联动走**表现层 + 事件层**（既视感的措辞、虚边的关联、回放的可见性），
  **不经 wiki**。这是本案能在不破坏 v3 的前提下成立的关键

## 9. 边界（本案明确不做）

- **不实现**（只留接口，§7）：creepiness 计算、阶梯推进、OS 表现、跨线回声
- **不做**"角色知道自己是代码/AI"的直白元叙事（退化为廉价梗，且与 §5 的 OS 定位冲突）
- **不做**惩罚机制（扣好感、锁剧情、强制事件）——用户 Q19 明确
- **不做**记忆跨线（`DESIGN_WIKI_V3 §11` 的硬语义保持）
- **不做**现实年份/玩家隐私信息泄露给角色（Q22）
- **不做**任何形式的"角色越过玩家与真人对线"（不代理、不联网、不发声）——这是安全边界，不是设计取舍
