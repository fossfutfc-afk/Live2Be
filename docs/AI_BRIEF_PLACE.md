## 2. 硬事实（每条一句，细节自己翻）

1. **一个 key 是一族图**，不是一张：时刻（夜/夕/清晨/雨雾）+ 作者差分（`X.jpg` / `X2.jpg`）。
2. **表键 ≠ 资产 scene_id**（`classroom` ↔ `class_room`）——翻译走 `files` 文件名，别猜。
3. **视觉键不进 LLM 上下文**（`place` / `place_asset` 都不进）。
4. **板级 `place_asset` 管板首段，段落级管锚点之后**——不串用，段落没写就回落默认图。
5. **层1 歧义不猜**（`天台` 指 3 个键）→ 下沉层2；**层2 的"词表里没有"不是失败**。
6. **缺素材 = 黑屏 + 报出来**（用户裁决），不是"换一张像的"。
7. **单图键 0 调用**；判不出/候选外/服务失败 → 保持当前画面（选错比不动更糟）。

## 3. 会带偏你的旧话（本文存在的主要理由）

| 你会读到的 | 真相 |
|---|---|
| `time_of_day` 字段 / "日夜那套" | **不存在**。时刻由第二遍选图判，判据是 scene 文本 |
| "给主 LLM 注入活跃键表（≤100 中文名）" | **作废**：主 LLM 零内容词表（唯一例外 = 镜头词） |
| "主 LLM 写 `place` 字段" | **作废**（记录流 v2：writer 只发 `switch`） |
| `config/settings/world/places.yml` | **已删**（PL4）；`paths.PLACES_PATH` 也没了 |
| "`_director_whitelist.json` 是现役词表" | 是**降级兜底**（表读不出来时才用） |
| "资产是 `BG_*` 一目录一场景" | 现在是 **`SDIR_*/DIR_*` 两级**（文件名不变，查库不受影响） |
| "`catalog.background(scene_id, variant)` 取图" | 取图**优先表的路径**：catalog 派生会漏 6 张时刻图 |
| "时刻/差分可以用关键词表判" | **被否**：范围成语/比喻+否定/成语/外语意愿句都会判反（四句反例在 prompt 里） |
| "`PlaceRetriever` 返回 scene_id" | 返回**表键**；要图走 `asset_scene()` |
| "缺素材就兜底一张别的图" | **被否**：黑屏 + 报出来 |
| "C 链路吃 `region`/`place` 判同地" | C 链路**没通电**；`node.place`/`place_raw` 照常物化 |
| "key 不可改 = key 永远不变" | 不可改是纪律；**改名会发生**，合法路径 = 只改表 + 写台账 |
| "改了表 writer 那边就更新了" | **不会**：writer 手里那份是**手写**的 `bond_shots.md`，两处都得动 |

## 4. 用户原话（判据的真源，别自己演绎）

- **核心逻辑**：*"主 LLM 可以随便写或仅仅掌握部分词表，然后由后台 LLM 标注；
  后台 LLM 由于任务极其单一，可以接受更复杂的巨大表单。"*
- **writer 的自由**：*"writer 当然可以说表外，为什么不能，writer 的自由不受限制，
  这个设计就是给 writer 最大自由防止注意力矩阵稀疏。"*
- **note 的作用**：*"annotation-llm 只要看到 note 就能大致推测出地点，这就可以了，
  而且关键地点还能给它当作注记注入 anno-llm，更加方便。"*
  **+ 2026-09-20**：*"我的部分 note 里面本身就会教 LLM 某些特殊常用的夜景以及差分
  的区别"* ⇒ note 就是**资源说明书**，选图那一步照办它。
- **镜头词**：*"比较特殊，是某些特效比如说 black 或者星空这种词，这是因为这些词
  能让 LLM 更好的写作。"*
- **时刻不归钟管**：*"一个玩家上了一天班……想和喜欢的角色看日出结果天空漆黑一片
  是吧？"* ⇒ 画面时刻由**剧本**决定，不由任何时钟决定。
- **动态读入**：*"这个表因为官方地点的更新是会进行更新或者调整措辞的，所以最好是
  动态读入而非写成死代码。"*
- **key 不可改 / 缺素材**：*"key 是不可改的"*；*"就用黑屏 black，且 alert/console.log
  素材未找到即可。"*
- **两轴**：*"key 需要用于回放，而 writer 名则需要用于检索，二者缺一不可。"*
