# CONTEXT_MARKS.md — 上下文里的括号约定（**一形一义**）

> 建立 2026-09-29（N5）。**极简**: 只回答"这个括号在她眼前是什么意思"。
> 判据只有一条：**同一个形状不许有两个意思**——本项目最贵的一类 bug 就是"同形不同义"
> （真机 art 命中率 0/5 就是示例形状与规则不一致造成的，陷阱 3/46）。
>
> 改动这里 = 改**她看到的形状** ⇒ 与规则书、契约示例**同批**改（`PROMPT_INJECTION_MAP.md`）。

## 表

| 形状 | 在哪 | 意思 | 谁写 |
|---|---|---|---|
| `【…】` | **行首独占一行** | **段的标题**（`【角色记忆（brain）】` / `【你想起的事（…）】` / `【手机上的日期】` / `【剧情时机】`） | 引擎（promptkit / render） |
| `〔…〕` | 记忆**行首** | **一条记忆的元信息**，段间用全角 `｜` 隔开：`〔《事件名》｜多久以前｜日期｜难忘〕` | 引擎（`render._meta_head`） |
| `《…》` | 只在 `〔〕` 里 | ⭐ **事件名 = 地址**（`episode.title`，逐字可抄；她用它指认 / 引擎用它查库） | 引擎（**原样**，绝不做第一人称转换） |
| `{"noticed": "…"}` | **她的输出** | ⭐ **想起行**（N5b）——她认出"这件事 = 某条旧事"时记的一笔账；**不上屏 · 不独占 · 不调 LLM** | 她（`engine._log_notices` 落账） |
| `（）` | 正文里 / 行尾 | **正文的一部分**（旁白、补注）；行尾那种里面装 `「」` = 逐字原话 | LLM（正文）/ 引擎（原话） |
| `「…」` | 只在 `（）` 里 | **逐字原话**（`verbatim`，她当时真说过的那句） | 引擎（从事件流取原文） |
| `[…]` | 历史消息**行首** | **动作名前缀**（`[mmt_chat] 话` / `[mmt_send_media]`） | 引擎（`_deliver_line` / `renderer`） |
| `{…}` | 全部 | **JSON 行**（她自己输出的形状；契约示例都是它） | 她（输出）/ 契约 |
| `<…>` | 契约文本里 | **占位符**（`{"action": "<动作名>"}`）——"这里要填东西" | 契约 |
| `·` | 词表 / 枚举 | **同层并列**（`星空 · 夜空 · 黄昏`）——⚠️ **不表示字段边界** | 提示词作者 |
| `｜` | 只在 `〔〕` 里 | **字段边界**（元信息段之间） | 引擎 |

## 三条纪律

1. ⭐ **`《…》` 在, 名字才在**：缺 `title` 的记忆行**不出名字段**（`〔3 天前｜9/27〕`）。
   ⇒ 指认的规则写成 **"照抄它的 `《…》`"**（按**书名号**找，不按位置找——
   位置规则在缺字段的行上会让她把时间段当成事件名）。
2. ⭐ **字段边界用 `｜` 不用 `·`**：`·` 会出现在事件名里（真机风格 `星空 · 夜空`），
   拿它当边界 ⇒ 她抄多抄少 ⇒ 查库命中 0 ⇒ **静默丢**。
3. ⭐ **锚点解析要剥格式**（书名号/尖括号/方括号/半全角引号/空白/`｜` 取第一段）：
   她连 `《》` 一起抄也必须命中；但**只剥格式、不做近似匹配**（近似 = 猜）。

## ⭐ 位置约定：**同一个括号，两个读者**（N2, 2026-09-29）

> **同构的是位置约定，不是逐字** —— 字段集随 kind 与读者变，这是有意的。

一条：**`〔〕` 里 = 这条的元信息；第一格 = 引用它要用的"钥匙"；括号外 = 正文。**

| 读者 | 行 |
|---|---|
| 她 · episode | `- 〔《中秋的杂草屋》｜4 天前｜9/27｜难忘〕中秋节晚上，社团的大家…` |
| 她 · belief | `- 老师是第一个不会嫌弃我的人` ← **没有括号**（元信息一个都没有） |
| L2 · 认知 | `〔u0001｜belief｜被引 3｜sig 0.97〕sensei对我的接纳：老师不只愿意听杂草…` + 缩进 `edges: …` |
| L2 · 新经历 | `〔m0025｜《今天的杂草屋》〕又去看了那盆苔藓…` |

1. ⭐ **钥匙随读者变**：她那边是**名字**（episode，正文 300~570 字必须摘名）或
   **正文本身**（belief，契约就要求 brief ⇒ **它的正文就是它的名字**）；
   L2 那边是**编号**（`u0001` / `m0025`）。这不是破例 —— 就是"编号退回引擎内部，
   给她看时映射成名字"那条的两面。⚠️ **编号绝不进她的视图**。
2. ⭐ **空字段不占位**：没有的段直接不出现（belief 没有时间 ⇒ 连括号都不出）；
   **一个字段都没有 ⇒ 整段不出现**（旧档逐字节不变）。
3. ⭐ **字段随 kind 变**（别按"必须一样"去补恒 0 的段）：`被引` 只给**认知**
   （它是"被支撑的靶子"才有的概念，episode 不印）；`sig` 只在珍贵档印。
4. ⭐ **两个 id 空间**（L2 专用）：**认知印本地号**（`u0001`，防 LLM 猜真实 id）、
   **episode 印真实 id**（`m0004`，R2 的 decisions 本来就用它）。
   指向列表外的认知 ⇒ **只报数**（`（另有 N 条边指向列表外）`），**绝不编号**。
5. ⚠️ **`「」` 只表示"逐字原话"**：L2 那边原来把标题写成 `「今天的杂草屋」`
   ⇒ 与她视图里"原话"同形不同义，N2 已改成 `《》`。
