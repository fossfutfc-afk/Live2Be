# EXPERIMENT_CAND_HIGH.md — `cand_high` 阈值标定实验（Q11, 2026-09-13）

> 目的（DESIGN_WIKI_V3 §10.2/Q11）：验证一个假设——
> **"真机 4/4 episode 全被判【疑似同主题】→ 结构强制禁 add"是不是单阈值造成的？**
> 方法：用真机 wiki（haruka 4 belief + 4 episode；mutsuki 3 + 2）复刻 Round B 的
> 碰撞过程，扫阈值 + 加**主题无关**对照组。全部读数见下，脚本在 `.testtmp/`（不提交）。
> 环境：nomic-embed-text-v1.5（LM Studio, 1234）/ Qwen3-Embedding-0.6B（llama.cpp, 1235）。

---

## 0. 结论（先看这里）

| # | 结论 | 证据 |
|---|---|---|
| **C1** | **单阈值调参在 nomic 下原理上不可能** —— 无关经历与相关经历**落在同一区间** | 见 §2 表: 相关 0.819~0.920 / 无关 0.743~0.868 |
| **C2** | **单阈值调参在 Qwen3 下原理可行**，且有清晰窗口 | 相关 0.682~0.859 / 无关 0.367~0.452 → 窗口 **(0.452, 0.682)** |
| **C3** | **现值 `0.50` 是错的**（两种模型下都错，但错法不同） | 见 §3 |
| **C4** | **Qwen3 下候选**排序**是准的**（不只是阈值问题） | 见 §4: 4/4 episode 的 top1 语义正确 |
| **C5** | **`must_touch` 的结构强制应降为提示**，与阈值无关 | 见 §5: 它把一个连续分数变成硬闸门，而分数带在**同一实体内部**天然压缩 |

## 1. 实验一：阈值扫描（证明"调阈值不够"）

forced% = 被判【疑似同主题】→ 结构强制禁 add 的 episode 占比：

```
cand_high  cand_med | 候选  forced  forced%  med_only
     0.50      0.25 |   16       4     100%         0
     0.70      0.25 |   16       4     100%         0
     0.80      0.25 |   16       4     100%         0
     0.85      0.25 |   16       3      75%         1
     0.90      0.25 |   16       1      25%         3
     0.95      0.25 |   16       0       0%         4     ← 全解放
```

**要解放"最难的那条"episode，阈值必须 > 0.92**（nomic 下）。
但"解放"不等于"判对"——它只是不再强制，LLM 仍可能选错。

## 2. 实验二（决定性）：加**主题无关**对照组

同角色、同语气、同第一人称，但主题与 4 条既有认知**无关**的四条经历：

| 经历 | nomic top1 | Qwen3 top1 |
|---|---|---|
| 老师拜托我调查杂草（相关） | 0.880 | 0.682 |
| 老师来到我的杂草屋（相关） | 0.894 | 0.859 |
| 给草取名春余被肯定（相关） | 0.819 | 0.710 |
| 检查三遍和每天看春余（相关） | 0.920 | 0.771 |
| **我在便利店买到最后一盒限定布丁…**（★无关） | **0.868** | 0.367 |
| **社团活动室的空调坏了…**（★无关） | 0.743 | 0.422 |
| **我把上周借的图书馆书还了…**（★无关） | 0.837 | 0.452 |
| **我在电车上给一位老人让座…**（★无关） | **0.867** | 0.445 |

```
nomic : 相关 [0.819, 0.920]   无关 [0.743, 0.868]   → 交叠, 无法分离 ❌
Qwen3 : 相关 [0.682, 0.859]   无关 [0.367, 0.452]   → 干净窗口 (0.452, 0.682) ✅
```

**nomic 的"无关"最高 0.868 > "相关"最低 0.819** —— 也就是说
**一条完全无关的经历，可能比一条真相关的经历得分更高**。
在这种模型下，任何单一阈值都必然同时产生假阳性与假阴性。这与
`AUDIT_2026-09-13_FULL.md §10` 的独立实测（nomic 下"天气 vs 量子色动力学"= 0.603）
互相印证：**nomic 把中文压进一条窄带，判别力近乎为零。**

## 3. 现值 `0.50` 错在哪（两种模型，两种错法）

| 模型 | 0.50 的实际效果 | 性质 |
|---|---|---|
| nomic | 无关 0.743 > 0.50 → **连无关经历都被判同主题** | 阈值**低于噪声底** → 假阳性灾难 |
| Qwen3 | 无关 0.452 < 0.50 < 相关 0.682 → 落在窗口**下沿**; 但把"同实体不同侧面"（0.444~0.55）也判越线 | 阈值**偏低** → 过度强制, 但方向是对的 |

**`0.50` 从未被标定过**（标定时 embedding 服务没通）——这是它错的原因，不是它"调得不好"。

## 4. 实验三：Qwen3 下候选排序其实是准的

| episode（haruka） | Qwen3 top1 认知 | 人工判读 |
|---|---|---|
| 老师来到我的杂草屋 | 向老师敞开秘密基地（0.859） | ✅ **完全正确**（她带老师去秘密基地，正文即"向老师敞开"） |
| 检查三遍和每天看春余 | 对老师的承诺方式（0.771） | ✅ 合理（她答应照顾草，天天去检查） |
| 给草取名春余被肯定 | 对老师的承诺方式（0.710） | 🔶 可辩（更像"被肯定的感受"，但 top2 0.633 也接近） |
| 老师拜托我调查杂草 | 向老师敞开秘密基地（0.682） | 🔶 可辩（事件是"答应帮忙"，与"承诺方式"更近） |

```
margin(top1−top2): 0.074 / 0.311 / 0.077 / 0.173     （mutsuki: 0.045 / 0.149）
```
**排序方向是对的，但 margin 波动大**（0.045~0.311）。所以：
**分数应当作为"给 LLM 的排序提示"，而不是"引擎的判定"。**

## 5. 对 Q11 的最终裁决（与 DESIGN_WIKI_V3 §6.3 呼应）

**三件事，按必要性排序**：

**(a) 换 Qwen3-Embedding（必要）** —— nomic 在这个任务上不可用（C1）。
这不是"优化"，是**前提**。代价实测：批量 40 条 143ms → 1716ms，digest 是分钟级后台路径，可接受。

**(b) `must_touch` 的结构强制 → 降为强提示（必要，且与阈值无关）**
`parse_round_b` 现在对【疑似同主题】的行**出 add 即整行作废**。这把一个**连续分数**
变成了**二元硬闸门**，而分数带在**同一实体内部**天然压缩（Qwen3 下同一实体的
不同侧面落在 0.44~0.86）——**语义相似度无法区分"同一件事"与"同一个人身上的不同侧面"**，
这正是 v3 提出第四轴的同一个洞察。
改为：标注 `→ 【疑似同主题】(sim 0.xx): u0002` **仍然给**，但 LLM 出 `add` 时
只需在 `note` 里说明理由（引擎记 NOTE，不作废）。

**(c) 阈值标定到窗口内（次必要，且可按模型配）**
Qwen3 建议 **`cand_high ≈ 0.62`**（窗口 (0.452, 0.682) 的中偏上），
`cand_med ≈ 0.40`。**但这条优先级最低**——因为 (b) 一旦落地，阈值只在"提示强度"
上起作用，不再能禁止 add。

## 6. 附带发现（值得单独记）

- **`cand_k=3` 掩盖了真相**：测量时若只看 `k=3` 的结果，会以为候选很稀疏；
  实际 `k=99` 下 4 episode × 4 belief = **16 个候选全部 > 0.73**（nomic）。
  即"每条经历都能匹配上每条认知"。
- **`local_of` 过滤会吞掉候选**：`_round_b_material` 里
  `cands = [(c,s) for c,s in cands if c.id in local_of]` —— 只标"本轮渲染进认知列表"
  的候选。认知列表 `COGNITION_CAP=12` 之外的认知**即使语义高度相关也不会被标注**。
  这是 §3.1"第 12 条以后不可见"的**第二个后果**（此前只指出"读不出"，其实**也组织不了**）。
- **mutsuki 的 `u0003` 是 `subject='player'`**（e0001 那条 experience）——
  它作为候选参与碰撞，但它的 `pattern` 讲的是"老师喝浓缩咖啡"。
  这条 v2 的错位节点（见 §1.2）**确实在污染组织决策**。
