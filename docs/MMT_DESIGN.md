# MMT_DESIGN.md — 主对话轮（MomoTalk）的设计

> **小稿子**（2026-09-27）。只写关键信息，不铺陈。
> 背景与真机证据在 `PROCEED.md §4` 与 `docs/DESIGN_DIGEST_LAYERS.md §0`。
> **状态：设计稿；代码未动。**

---

## 0. 一句话

> **MMT 的设计目标是：让她在「该想起」的时候想起，且不为此多付一次调用。**

三个落点：**提示词形式**（三种行）· **inspect**（要东西进来的慢路）· **link**（把发现送出去的记录行）。

---

## 1. 提示词形式：**三种行，三种性质**

今天的行协议只有两种（`{"text":…}` 消息行 / `{"action":…}` 操作行）。本轮加第三种。

| 行 | 形状 | 性质 | 上屏 | 代价 |
|---|---|---|---|---|
| **消息行** | `{"text": "…"}` | 创作 | ✅ | —— |
| **操作行** | `{"action": "mmt_…", "payload": {…}}` | ⭐ **动作**（要东西**进来**） | ❌ | ⚠️ **一次静默轮 + 回灌** |
| ⭐ **记录行**（新） | `{"noticed": {…}}` | ⭐ **顺手记账**（把东西**送出去**） | ❌ | ⭐ **零** |

### 为什么要分开

⭐ **把"动作"和"记账"混成同一种行，她就会对两件事都产生"我要不要执行它"的判断** ⇒ 习惯性伸手。
记录行**零代价、不影响本轮、不参与一行前瞻** ⇒ **她不需要"决定"**。

### 三条纪律（都是踩过的）

1. ⭐ **示例才是形状的来源**（陷阱 3/46）—— 改契约**必须同批改示例**，否则白改
2. ⭐ **提示词里的"反例"会变成禁令**（陷阱 40）—— 写 ✗ 之前先问"我们要的那种输出会不会撞上它"
3. ⭐ **看不见两端的 LLM 写不出那条边** —— 她判得出什么，取决于**引擎把什么放到了她眼前**

---

## 2. `inspect` —— 慢路（要东西**进来**）

### 机制（已有，不动）

- **静默推理轮**：按 `interperson` 权重访问他人人设（1 = profile / 2 = +personality / 3 = +experience）
- **查到的资料回灌后继续这一轮**
- **一行前瞻**：下一行是 `inspect` ⇒ **把手里那行丢掉**（"没查到就先答"）
- **独占行**：攒到块尾判（独占性 = "同一轮还有没有别的行"）

### ⭐ 不退役（2026-09-27 用户裁决）

> 用户：*"以后会有多人模式，会出现本来不认识的角色之间熟悉的情况，这就要 inspect entity；
> 而且现在 wiki 较小……但凡 wiki 变大 / 玩家问起，我想不出这个东西为什么要退役；
> **不要为了解决这个问题把其他东西给丢掉了**。"*

⚠️ **我曾用"真机 157 轮 0 次调用"论证它该退役 —— 那违反了陷阱 24**
（*"别拿真机数据频率论证价值 —— 没压过的地方就是 0"*）。

### 补一条**快路**（不是替代）

| 路 | 手段 | 解决什么 |
|---|---|---|
| ⭐ **快路** | **预装"名字 + 一句话"**（真机 haruka 只要认识 3 个人 ⇒ 几十字） | 高频的"**知道那是谁**" |
| **慢路** | `inspect`（契约不动） | **多人场景 / 要细节 / 玩家问起** |

**两条都要。** ⚠️ 这也是我本轮犯的错：**拿"膨胀"当理由去砍能力。**

## 3. `link` —— 发现相同（把东西**送出去**）

### 3.1 定位：⭐ **Link 是 MMT 的活**（2026-09-27 用户收口）

**根因**：我们是**流式**的，而 link 与 collision 都要求**批量回看**。
⇒ **link 由 MMT 每轮在对话中发现**（她有"当下"当线索）· **collision 由 L2 离线派生**（要整组）。

**一石五鸟**：绕开 O(wiki) 的 LLM 成本 · **不预建类别**（不膨胀）· **当下即触发**（不要阈值）·
**保留细节**（她手上是具体那一条）· **可校验**（强制锚点）。

### 3.2 形状：**记录行，不是 action**

```json
{"noticed": {"anchor": "瓦片缝里的苔藓", "quote": "人行地砖里的苔花也是花", "what": "他记住了我随口说的话"}}
```

| 字段 | 是什么 | 谁校 |
|---|---|---|
| ⭐ **`anchor`** | **主锚**：她抄一条**标题**（8-16 字，好抄、直觉） | 引擎在 title 里查 |
| **`quote`** | **副锚**（可选）：一句逐字原文 | ⭐ **title 重名时消歧** + **存在性校验** |
| **`what`** | ⭐ **"相同的是什么"**（一句话）—— **不是类别，是那件具体的小事** | — |

⚠️ **`what` ≠ `aspect`**：
- `what` = **这一对的具体相同点**（她给的，每次都不同）
- `aspect` = **L2 归并出的可复用维度**（只有 L2 知道"这个相同点已经第 N 次出现"）
⇒ ⭐ **她手上只有 1~2 条，凭什么都看不出"类别"** —— 所以类别不归她。

### 3.3 ⭐ 她给不了坐标（这是关键）

`render._memory_line` 印的是：

```
- （3 周前·难忘）她拉着我在杂草屋蹲了一下午。（「苔花也是花」）
      ⚠️ 没有 id、没有 seq
```

⇒ **她看不到 id，也看不到 seq，只看到正文** ⇒ **她能给的唯一稳定标识是「短标识 + 逐字引用」。**
⇒ ⭐⭐ **所以要给她一个可抄的短标识** —— `episode.title` **早就有了，只是从来没印出来**（"写好了没接线"）。

### 3.4 ⭐⭐ 同一条轴上的区间

```
episode      = [a, b]                        ← 已固化（N3 区间化之后）
"当下"        = [last_b + 1, current_seq]      ← 本段**还没被 episode 化**的那部分
两者都在同一条轴上 = event_seq（append-only 真源，单调递增）
```

⇒ **"当下"是确定性的**（上一个 episode 的终点 + 1，到当前 seq）⇒ **她的锚只需要指"过去那一端"。**

### 3.5 完整链路（**只有第一步是 LLM 的**）

```
① 她说：{"noticed": {"anchor": "瓦片缝里的苔藓", "what": "…"}}

② 引擎解析 anchor → 定位唯一 episode
   · 命中 0 条  ⇒ ⭐ 丢（编造）—— nacre 的强制锚点
   · 命中 ≥2 条 ⇒ quote 精确匹配优先 · 再取最近 · 仍有歧义 ⇒ **不猜**（宁缺勿错）

③ 引擎算"当下"区间 = [last_episode.b + 1, current_seq]

④ 落边：same_kind{seq 区间 → episode id, what}
   （发现时有向；落库规范化成无向 —— `canonical_pair`）

⑤ L1 跑完 ⇒ 引擎**提升**：seq → 它所属的 episode id
   （episode 自带 event_seq，**二分定位** O(log n)）；没被认领 ⇒ 边留在 seq 上，不进群

⑥ L2 分群 ⇒ 只收"两端都是 episode"的边 ⇒ 干净
```

⭐ **"混类型端点"不是缺陷** —— 它如实表达"**我这一句话，印证了那件旧事**"。

### 3.6 ⭐⭐ 而它同时改进了"发现"本身

**标题里的具体名词，恰好就是"细小的相同"的候选维度**：

```
瓦片缝里的苔藓
约老师来看苔藓
分给夏莱的一小株苔藓
```

⇒ ⭐ **她扫一眼标题就能发现"这三条都有苔藓"** —— **比读三遍正文快得多。**
⇒ **所以"统一短标识"不只是"好抄"，它让「发现相同」变成「扫一眼标题」。**

## 4. 她每轮手上有什么（"手边"）

```
① 她是谁                        ← 盒A（静态）
② 老师是谁 + 她怎么看           ← L3 动态基线（短）
③ 答应过什么 / 此刻在想什么      ← note（promise + on_mind）
④ 发生过什么（**标题 + 时间**）   ← ⭐ 骨架（真机 18 条 ≈ 270 字，今天 2644 字）
⑤ ⭐ 这一轮「想起的 1~2 条」      ← 引擎摆（**孤立点优先**）—— 唯一的动态位
⑥ 别人是谁（名字 + 一句话）      ← ⭐ 预装（快路）
```

### ⭐ 判据不是"信息够不够"，是"**她会不会想伸手**"

| 她想伸手要的 | 走哪条 |
|---|---|
| 别人是谁 | ⭐ **快路：预装** · 慢路：`inspect` |
| 这轮想起什么 | ⭐ **引擎摆**（每轮 1~2 条） |
| 那件事的细节 | **refs 走法**（引擎注入时预取） |

### ⭐⭐ 为什么"每轮摆"不是"全量注入"

| | 全量注入（bucket） | **线索**（每轮摆的） |
|---|---|---|
| 提供 | **信息在场** | ⭐ **"这条与当下有关"的标记** |
| 每轮变不变 | ❌ **不变**（静态快照） | ✅ **变** |
| ⇒ 后果 | ⚠️ 每轮同一套 + 不印边 ⇒ **内部自循环** | ⭐ 破自循环 |

**摆什么的依据**：⭐ **`same_kind` 入度 = 0（孤立点优先）** ——
确定性 · 不依赖相似度（破冷启动）· 连过的不再孤立（破自循环）· 覆盖式 · 每轮不同。
⚠️ 我们已有雏形：`recall_subgraph` 的**通道 3「随机摘段」**（零产品调用者）—— 把"随机"换成"入度=0 优先"。

## 5. 情形表（遇到什么 → 怎么做）

| 情形 | 她做什么 | 引擎做什么 |
|---|---|---|
| 玩家提到一个她不认识的人 | `{"action": "mmt_inspect_character", …}`（静默轮） | 按 `interperson` 权重取人设 → 回灌 → 继续本轮；**一行前瞻把手里那行丢掉** |
| 玩家的话让她想起旧事 | ⭐ `{"noticed": {anchor, what}}` | 锚点校验 → 落边 → L1 后提升 → L2 派生 |
| 她答应了一件事 | **正文里说**（创作） | R4/L1 收口进 note 的 `promise` |
| 她此刻心里挂着什么 | **正文里说** | L1 写 `on_mind` |
| 一轮里既要查又要说 | 两行都输出 | **独占行攒块尾判**；查的那行让内容行被丢 |
| 她引用的旧事在标题里重名 | 补一句 `quote` | quote 精确匹配消歧；仍歧义 ⇒ **不猜** |
| 她说的这事当下还没成 episode | —— | 边先落 `seq → episode`；L1 后**二分提升** |
| 她想说话但没有该引用的 | ⭐ **什么都不写** | `noticed` 是**可选**的 —— 它是"顺手"，不是"任务" |

## 6. 相对其他项目：我们解的是什么

| 项目 | 它怎么做 link | 它的空白 |
|---|---|---|
| **AgentGal** | ⭐ **`linked_episodes` 由流程层机械注入**（LLM 零参与）；**episode 之间没有边**；"多个事件"靠**检索** | ❌ 只做 **A→C→B**（增量 patch），**不做 A+B→C** |
| **Hindsight** | 三类边：temporal / semantic / **causal（加权最高）**；⭐ **entity link = 共同提及两两连边** | ⚠️ 共现**不区分角色**（"独处"与"别人谈论他"混为一谈） |
| **GraphRAG** | local = 图遍历 · global = **社区摘要**（Leiden 算法切） | 社区是**算法切的**，不是"发现的" |
| **Zep** | 双时态 `t_valid/t_invalid`（失效不删） | —— |
| **ST World Info** | **关键词命中**（零语义） | —— |
| ⚠️ **Mem0 v2** | ⚠️ **把图删了**（"~4000 行图驱动代码移除"） | 反例：**图不是免费的** |

### ⭐⭐ 两条别人没解的，正是我们的两个设计点

| # | 空白 | 我们的解 |
|---|---|---|
| **1** | **没有一家把 link 交给对话轮**（都是离线算 / 机械注入 / 关键词匹配） | ⭐ **Link 移交 MMT**：她有"当下"当线索，成本摊到每轮，且锚点可校验 |
| **2** | **没有一家做 A+B→C**（跨事件派生新命题） | ⭐ **L2 的 collision**：对过闸的整组**重派** C（输入是**整组全文**，不是旧文本） |

### 我们同时避开的两个坑

| 坑 | 谁踩的 | 我们怎么避 |
|---|---|---|
| **"共现即同类"** | Hindsight | ⭐ 维度是 **"对象 × 角色"**（在场 / 话题 / 施与 / 受益），不是"提到了谁" |
| **pairwise 判同类** | ——（业界没人做） | ⭐ **实测阈值不存在**（组内最低 < 组外最高，最差 **0.425**）⇒ 改用**维度枚举 + 整组抽取** |

## 7. 解决了的清单

| # | 问题 | 解 |
|---|---|---|
| **1** | `episode↔episode` 边 **0 条**（写边的那个 LLM 视野里没有旧经历） | ⭐ **noticed 记录行** + **title 做主锚** |
| **2** | **框架锁死**（模式判断在 n=1 时就下 ⇒ 句首框架永远来自第一条） | ⭐ 硬规则：**模式判断（频率词）在 `n ≥ 2` 之前不许出现**（可机械校验） |
| **3** | **发现不了相同**（静态快照 + 不印边 ⇒ 内部自循环） | ⭐ **每轮摆 1~2 条孤立点** + **标题即索引** |
| **4** | **抄不准**（她看不到 id/seq） | ⭐ **统一短标识**（`episode.title` 早就有了，只是没印） |
| **5** | **习惯性伸手 / 膨胀** | ⭐ **记录行零代价**（不是 action）· **快路预装** |
| **6** | **两套时间不对齐** | ⭐ **同一条 seq 轴** + **二分提升** |
| **7** | 注入 **4293 字**（episode 全文 86%） | ⭐ **标题骨架 ~270 字 + 按需正文** |

## 8. 明确不做 / 未定

### 不做

| 项 | 为什么 |
|---|---|
| ❌ **把 `noticed` 做成 `action`** | 那她就有两个要靠"觉得需要"触发的口子 ⇒ 习惯性伸手 |
| ❌ **要求她记 id / seq** | 她看不到（`_memory_line` 不印） |
| ❌ **让她输出"类别"（aspect）** | 她手上只有 1~2 条，看不出类别 ⇒ 类别是 **L2 的产物** |
| ❌ **退役 `inspect`** | 多人 / wiki 变大 / 玩家问起必须要它（⚠️ 我犯过这个错，见 §2） |
| ❌ **在视图里印边** | 加字数；"孤立点优先"从入口上就不重复 |

### 未定

| # | 项 |
|---|---|
| 1 | **`anchor` 与 `quote` 的必填/可选关系**（倾向：`anchor` 必填、`quote` 可选） |
| 2 | **title 重名的消解顺序**（倾向：quote 精确 → 取最近 → 不猜） |
| 3 | **每轮摆几条**（1 还是 2）· 预算按字符还是条数 |
| 4 | **预装"别人是谁"的字数上限**（真机 3 人 ⇒ ~几十字；世界变大后要重估） |
