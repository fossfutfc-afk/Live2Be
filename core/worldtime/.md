# worldtime/ — 时间

**作用**：时间这个**横切关注点**：现实日期怎么算成"多少天前"、月份/闰日怎么位移、
她嘴里的"上周""圣诞节前"怎么翻成检索窗口、以及往 prompt 里注入的时间注记。

⭐ **唯一日期轴 = 现实日期**（`node.ts`）。剧情日历（`story_time` / `sim_day` / 世界时钟）
已作废 —— 它是"里程表冒充日期"。所以这个包里**没有第二个时钟可算**。

## 为什么单独成一个包

1. **它不 import 项目内任何模块**（只依赖 stdlib）—— 这是"独立设计"的可验证定义；
2. **依赖方向不能反**：若时间住在 `core/brain/`，渲染层要拿"3 周前"就得 import 记忆模块。
   时间是横切件，不是记忆的子概念。

包名不叫 `core/time/`：全库有 7 处 `import time`（stdlib），同名包只会制造歧义。

## 模块

| 模块 | 管什么 | 不管什么 |
|---|---|---|
| `age.py` | **双出口**：连续 `age` → `freshness`；同一 age → `render_relative` 短语（另有绝对日期 `render_date`） | 不排序、不知道 score |
| `cal.py` | **日历算术**：位移 + 夹取（月末 / 闰日 / 周首日），纯 stdlib | 不做语法、不认人话 |
| `when.py` | ⭐ **她写的时间 → 检索窗口**：`last` / `back` 两族 + 绝对形式 + 人话容错 | 不读壁钟、不从整句里抽时间、不猜 |
| `prompt_time.py` | **进 prompt 的时间注记**：手机日期 / 现实间隔 | 不读盘、不判定 |
| `realtime.py` | **现实日历**：特殊日期表（生日 / 节日）+ 触发幂等 + `real_clock.json` 台账 | **只做由头，不做时钟**（不持有任何时钟） |
| `span.py` | LLM 面对的时间语法（枚举 + 校验） | 不做进位、不做衰减 |

⚠️ **`when` 与 `span` 不是重复**：`span` 是"LLM 说**跨了多久**"（叙事粒度，今天无运行时
消费方）；`when` 是"她问**哪一段时间的事**"（检索区间）。一个管叙事事实，一个管检索。

## 三条硬边界

1. **不 import 项目内任何模块**（违反即失去独立性）。消费方单向依赖它。
2. **时间概念在这里，打分概念不在这里**：`freshness`（∈[0,1] 的新鲜度）在这里；
   `det = SIG·freshness + emo_span·emo_int` 在 `core/brain/read/channel_impl.py`。
   否则这个包迟早长出"权重"概念。
3. **没有"两个时钟互算"**：`realtime` 与 `age` 各算各的，互不引用。

## 纪律

1. **不读壁钟**：凡要"现在"，一律是必填参数（`age_days(*, now=…)` 不留默认值）——
   否则测试与 replay 会落在两个时刻上，同一个 prompt 里出现两条不同源的日期。
2. **宁可返空，不猜**：`when` 认不出的语法一律给空窗口（"没听懂"比"猜错一段"便宜）。
3. **边界只有一处**：周首日、月末、闰日、跨年全在 `cal.py`；别在别处手写 `+30 天`。
4. **注记是注记**：时间注记只进 prompt，不参与任何判定（不进 det / age / 召回）。
5. **`realtime` 只做由头**：它回答"今天是不是那个日子"，不推进任何时间。
