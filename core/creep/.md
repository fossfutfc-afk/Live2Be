# creep/ — 世界线的账

**作用**：记**引擎/世界的元事实**（"这一段没能消化成记忆"），不是剧情、不是事件、不是记忆。
一条账 = `soul/events.jsonl` 里 append-only 的一行，但**谁也读不到它**：账行没有 `seq`，
`Event.from_dict` 的第一道校验就把它挡在外面 —— 隐身是**结构性**的，不靠白名单纪律。
所以它不进上下文窗口、不进 `wiki.jsonl`、不进记忆。它与 `real_clock.json` 的 `rewind_count`
同级（都"算不出来" ⇒ 都是自家真源），区别是**账跟线走**（住在世界线里，不是世界级文件）。

## 核心文件

| 文件 | 是什么 |
|---|---|
| `ledger.py` | 真源：行形状（`make_row`）· 造行（`build`）· 写（`record`）· 严格读（`read_raw`） |
| `skeptical.py` | `kind` → 一句第一人称的"存疑"：每个 kind 一个池子，落账时随机取一，**写时冻结** |
| `__init__.py` | re-export；调用方只认 `core.creep` |

## 现状：只留了接口

**已落**：行 + 写 + 严格读 + 两个写者 —— `digest_skip`（digest 试满 3 次放弃一段）与
`digest_gap`（这一段跑成了，但契约层当场丢了东西；见 `digest/pipeline.py::_note_gap`）。

**还没做**，别以为它在跑：

* **让她看见** —— `kind` → 存疑文本 → 每轮注记。文本池有了，**注入口没接**。
* `[creep]` 开关（连读侧都还没有）、`cval`（世界线的"墙被推开多少"）、解锁（OS / 记忆编辑）。
* 别的 `kind`：候选列在 `ledger.KINDS` 上方（`time_rewind` / `node_overwrite` / `dangling_ref`），
  **只加有写者的**。

## 五条纪律

1. **账不可重算**（wiki 能从事件流重算，账不能）⇒ 写失败**不许静默降级**。`record` 会抛，
   调用方自己决定要不要 try，但别在 `record` 里吞。
2. **开关只影响读、永不影响写**：否则账随配置漂移，将来的 `cval` 不可复算。
3. **`type="creep"` 永不进 `EVENT_TYPES`**：它靠"没有 seq"隐身，别给它发号。
4. **写入路径唯一** = `SessionStore.append_raw_row()`（拿 `append_event` 那把锁）；
   本包自己不碰文件，锁与"无 seq"约定只有一处。
5. **读侧严格、写侧宽容**：别人的解析器宽容丢是我们想要的，**自己的**宽容丢是危险的
   （写歪一个 kind 会永远查不出来）⇒ 坏行一律 `logger.warning` + 从 `bad_out` 出去。

## 存疑文本的三条措辞纪律（改词前必读）

**不可验证**（只能是"淡下去 / 抓不住 / 说不清"，不许"被删了 / 被改了 / 你回档了 / 系统出错"）·
**不归因**（永不说"因为 X"）· **一句、短**（≤30 字）、不点名任何机制。
理由：错位一旦可被某个观察者验证，它就从"氛围"变成 bug —— 玩家能验证 ⇒ 像 bug，
LLM 能验证 ⇒ 它会去圆（破墙）。
