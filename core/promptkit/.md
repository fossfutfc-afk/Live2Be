# promptkit/ — 提示词装配层

**作用**：决定**一次请求里 system / user 各是什么、按什么顺序拼**。它**不写文案** ——
规则书住在 `llm/prompts/*.md`、输出契约住在 `contract/`，这里只负责取哪份、填什么槽、
放在第几段。装配的真源就是 `box.py` 的 `DOMAIN_BOXES` 与 `tail.py` 的 `round_messages`。

**每个调用点实际长什么样**：见 [`docs/PROMPT_SAMPLES.md`](../../docs/PROMPT_SAMPLES.md)。

## 三种注入时刻

| 档 | 内容 | 代码 | 特征 |
|---|---|---|---|
| **会话级一次** | 盒 A（MMT system）/ 盒 B（Bond system） | `box.build_box` | 进会话/进剧情时**拼死**，之后逐字节复用（吃上下文缓存） |
| **每轮 / 每场动态** | 注记们 · 任务卡 · 记忆段 | `tail.round_messages` | 一律落在 `history` **之后**；只进 context，不入历史 |
| **异步独立调用** | 情绪标注 / 地点标注 / digest 各轮 | `core/bond/*` · `core/digest/call.py` | 不占玩家等待主路径 |

## 核心文件

| 文件 | 是什么 |
|---|---|
| `box.py` | 盒 = 域 → **块 id 有序清单**（`mmt` 10 块 / `bond` 10 块）；`build_box` 逐块渲染后 `\n\n` 连接 |
| `blocks.py` | 块实现：`greeting` / `persona_*` / `world` / `*_tone` / `environment_mmt` / `time_sense` / `rules_*` / `bond_shots` / `schema` / `place_world` / `brain`；返回 `None` = 该块缺席（不占位） |
| `tail.py` | **每轮装配的唯一入口** `round_messages`：`[system(盒 + brain 段)] + history + [注记们] + [任务卡] + [user]` |
| `task.py` | 任务卡（目标层，末位）：模板 = `llm/prompts/task_*.md`，只在 `{{char}}` 有值时才填 |
| `report.py` | 注入报表（`describe()`）：这一域**实际注了哪几块**、每块多少字（排查用，不生成 prompt） |
| `config.py` | `settings.toml [promptkit]` 那组开关（今天只有 `task_card`） |

## 纪律

1. **盒里只放"一次拼死"的东西**：会随经历变化的内容（她的记忆视图、备忘录、时间、召回）
   必须住**动态段** —— 进盒就逐轮破前缀缓存。
2. **动态一切发生在 history 之后**：`round_messages` 的落点是硬要求，不是排版偏好。
3. **文案是数据不是代码**：改句式改 `.md`；改"注什么、第几段"才改这里。
   两边都会动 prompt 字节 ⇒ 都要跑三份逐字节判据 + 刷黄金夹具（`tests/core/test_promptkit_baseline.py`）。
4. **缺席块不占位**：块返回 `None` 就整段消失（少一段上下文，剧情照走 —— 宁缺勿错）。
5. **填槽不许静默**：槽统一走 `contract.slots.render_template`；模板有槽没给值、或给了不存在
   的槽，**当场炸**（从前 `.replace` 是静默空转，`bond_story_rules` 就白改过一次）。
