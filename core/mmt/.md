# mmt/ — MomoTalk 对话引擎

**作用**：实现"玩家和角色在类微信里聊天"这一域。一轮 = 玩家说一句 → 主 LLM 输出**行流**
（一行一条 JSON）→ 引擎逐行判定、逐行落事件、逐行上屏。所有**判定**（合法动作、形状、
兜底）都在引擎里，LLM 只负责演。

## 主循环：一行一条 JSON，边收边办

入口 `MomoTalkEngine.agent_turn(user_input)`,真正干活的是 `_turn_lines`。一轮最多
`MAX_STEPS` 步;每步: 发 LLM(裸文本)→ 解析行 → **按行的类别决定办理时机**。

| 行的类别 | 办理时机 | 为什么 |
|---|---|---|
| 消息行 `{"text": …}` | **到达即交付**(边收边上屏) | 首字与末字都取它能到的最早时刻 |
| 内容操作行(`send_media`) | 到达即交付 | 同一条流水线 |
| 独占行(`WHOLE_TURN_ACTIONS`) | **块尾**(整轮写完) | 合法性取决于"同一轮还有没有别的行",早判必错 |
| 想起行 `{"noticed": …}` | 收在手里,**轮末统一落账** | 它是**账目**不是内容(不上屏、不调 LLM) |
| 坏行 / 空轮 / 形状 | 块尾 | 形状要整段才看得出来 |

单行的办理是一条固定的四段流水线(`_run_lines` / 单行版 `_plan_line`):

```
① 自愈 mmt_repair   （零 LLM: 写歪的字段就地修; 修不了才丢）
② 组合校验 mmt_check（独占性 / 标题长度 / 空轮 —— 要看整轮）
③ 解析 + 执行        registry.parse(白名单动作) → executor.execute
④ 交付 _deliver_line （落事件 + 进历史 + 出气泡; **保持行序**: 话→图→话 就是 话→图→话）
```

⭐ **行交付即落库**：事件在那一行交付时就 `append`,不是整轮成功才写 —— 所以
**已经说出去的话收不回**（块尾判出硬问题时：独占行不执行 + 记一条注记给下一轮,
不把整轮标成"发送失败"）。

**三段兜底**（分级见 `docs/DESIGN_STREAM_CONTRACT.md` §4）：

1. **引擎自愈**（零成本, 每行先跑一次）;
2. **行级续写**（`LINE_REASK_MAX`）：让模型只补**缺失的那一条操作行**, 已说的话不许重复;
3. **形状级整轮重发**（`SHAPE_RETRY_MAX`）：整段不是 JSONL 时重发;

三段都耗尽 → `MmtLoopError`（只有"什么都没交付"时才抛 —— 玩家没看见东西, 失败才是真的）。

**查询族**（`look`）查到资料后**回灌 prompt 继续同一轮**, 不是另起一轮：它属于
"静默推理轮", 那一轮本来就不产出可见内容, 所以 `need_more` 不算失败。

## 核心文件

| 文件 | 是什么 |
|---|---|
| `engine.py` | 引擎本体: 会话 / 每轮装配 / **行协议主循环** / 逐行落库 / 收尾 / digest 触发 |
| `mmt_lines.py` | 行流解析：文本 → `MmtLine`（内容行 / 操作行 / 想起行 + 诊断） |
| `mmt_repair.py` | 操作行的**引擎侧自愈**（零 LLM） |
| `mmt_check.py` | 回合级校验：码表 + 组合约束（独占性、标题长度、空轮） |
| `mmt_actions.py` · `mmt_executor.py` | 动作定义（`mmt_` 前缀）与按 `approval=auto` 执行 |
| `mmt_preset.py` | CLI 预设：角色选择、斜杠命令、玩家名（面向人，不参与引擎判定） |
| `mmt_registry.py` · `ranking.py` | 桃信白名单（`config/settings/mmt_registry.toml`）与列表排序 |

## 每一轮的上下文（`agent_turn` 装配）

`round_messages` 是**唯一装配入口**：`system`(盒 A + brain 段) → `history` → 注记们
(时间 / 每轮召回 / `system_note` / 随机事件) → task 卡 → `user`。
注记与任务卡**只进本轮 context, 不进历史**;`system` 前缀要逐字节稳定（吃上下文缓存）。

## 纪律

1. **判定不许让 LLM 做**：合法性、形状、独占性、兜底全在引擎 —— LLM 写错由引擎修或拒,
   而不是"相信模型会照做"。
2. **行 = 交付单元 = 落库单元**：一条 `MmtLine` 一个气泡、一条事件；两者的边界必须是同一个,
   否则刷新页面会看到"没说过的话"或"少了一句"。
3. **已交付的不回滚**：兜底只朝"补上缺的那条"使劲, 不重写已经发生的事实。
4. **失败要能 grep**：每条降级都带中文串（`行协议: 丢掉办不了的行…` / `mmt_turn … late_issue=1`）,
   只打数量等于没打。
5. **宁缺勿错**：召回 / 随机事件 / 注记失败一律不阻断对话（`except Exception` + warning）。
