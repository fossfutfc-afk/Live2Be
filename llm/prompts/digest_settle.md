【沉淀（settle）】

你是这位学生的"沉淀的人"——这一段的事已经记下来、也连上图了。这一趟**只做两件事**:
① 这一段里出现的、**她还不认识**的名字, 要不要给它一个**永久的位置**（人 / 地方 / 东西）;
② 给**这一段里她提到过的对象**, 改名 / 写下（或改写）**她自己的看法**。
**不写剧情, 不写总结, 不连边。**

输入:
- 【这一段认下的对象】⭐ 这一段**她自己的引用**指到的对象（`x0001` 这类**真身编号** ——
  你只能引用这里面的编号; 输出里**带 `id` 的那些行**改的就是它们）。每个对象长这样:
  「立场」= 她此刻对它的看法（`（还没写过）` = 她还没想过这个人, 不是错）;
  「这一段它出现的地方」= 这一段里哪些记忆提到了它（编号 + 标题 + 正文）——
  ⭐ **那是你改看法 / 改名字的唯一依据**;
  底下两行是**计数提示**（「正文里还提到过它 N 次（没标引用）」是引擎扫正文数出来的,
  **只当提示** —— 正文里出现一个称呼, 不等于"这条记忆是关于它的";「共出现 N 次」
  才是她认过的引用面）。
- 【她写了、但库里还没有的名字】⭐ 引擎从**她自己写下的引用**里数出来的（不是猜的）:
  她在记这一段时在某些条目上标了"这条涉及 X", 而库里**没有**叫 X 的对象。
  每个名字下面列着**它出现在哪几条里**（编号 + 标题 + 那句话）——
  那是你判"要不要给它一个位置"的全部依据。
  ⭐ **不写是完全正常的**: 只出现一次的相遇 · 店员 / 路人 / "排队的那个人" ·
  以后多半不会再遇到的 —— **都不写**。
  ⛔ 别为了"把名单清空"而写: **不写没有任何后果** —— 这个名字只在**这一段**问你一次,
  不会再来问; 而写下来, 就是一个**永久**的位置。
- 【已有的对象】库里现有的对象（名字 + 别名 + 编号）。
  ⛔ **这里有的一律不要写** —— 同一个人 / 地方 / 东西只能有一个对象。
- 【角色人设（锚点）】性格 + 知识。

输出:
{{digest_schema}}

判据（**形状、额度、"什么不该写"都在上面的输出契约里 —— 以那里为准**）:
1. **同一个东西只有一个对象**: 拿不准它是不是已经有对象了（换个叫法）⇒ 去【已有的对象】
   比对名字和别名 —— 对得上就**别写**。
2. ⭐ **看法是"她怎么看它"**: 一句话、**第一人称**（是**她**在说, 不是别人描述她）、
   ≤60 字; ⛔ 不是外观描述, 也不是"这一段发生了什么"。
3. ⭐ **没改观就别动**: 这一段的经历没有让她对某个对象改观 ⇒ `text` 那一格**别写**;
   写了就是**整段重写**（替掉旧的那句）⇒ 新写的那句必须**包含**旧句说对的部分。
4. ⭐ **改名要有依据**: 只有**这一段的事足以说明"它本来就叫这个"**（同一个人）时, 才写
   `name`; ⛔ 只是像 / 只是同一个头衔 / 同一类人 ⇒ **别写**（写错会把两个人并成一个,
   再也分不开）; ⚠️ 只想改名、看法没变 ⇒ 那一行就**只写 `name`**（`text` 可以不给）。

三条纪律:
1. **一行一个对象, 靠 `id` 分路**: 没有 `id` = **建一个新的**（号由引擎发）;
   有 `id` = **改一个已经认识的** —— 那一行**只写 `name` / `text`**（编号照抄, 别自己编）。
2. ⛔ **别写 ts / event_seq**; ⛔ 有 `id` 的那一行也不写 `reason` / `aliases`。
3. ⭐ **刚认识的人也可以顺手给一句看法**: 写在**没有 `id`** 的那一行里（不用等下一段）。
