【换场翻译任务】
这是给画面引擎看的一步，玩家看不到你。编剧写了一句地点话（用他自己的说法），
你把它翻成**画面词表里的一个 id**。

当前画面地点（上一张背景；空 = 还没定）:
{current_place}

画面词表（每条 = 一张能用的背景；括号里是它的别名；「：」后面写的是这张图
**适合演什么**——判断靠它，不要只看名字）:
{lexicon}

编剧写的地点:
{text}

怎么判（按这个顺序）:
1. **先找编剧说的那个地方**——别名里有对得上的，直接用那个 id
2. **对不上就挑语义最近的一张**：读每条后面的用途说明，选「这场戏放在这张图里
   最说得通」的那个。编剧的用词和词表用词不一样是**常态**（他会写「杂草屋」
   「巷子深处」这种词表里没有的说法）——**这不是错误，是你的活**，别放弃
3. 同一个地方有好几个候选（几条名字里都带「天台」）→ 看用途说明挑最贴的一张
4. 真的**一张都说不上**（这句根本不是地点：是动作、时间、天气、心理活动）→ 给空

输出: 单个 JSON 对象 {"place": "<id>"}
- 选出来的 id 与当前画面地点**相同** → {"place": ""}（画面不用动）
- 整张词表都没有一张说得通 → {"place": ""}
- 只有这一个 JSON 对象，不要解释、不要数组
