【换场翻译】
编剧写了一句地点话（用他自己的说法）。你把它翻成**下面词表里的一个 id**。
玩家看不到这一步，你只需要给出那个 id。

当前画面（上一张背景；`（还没定）` = 本场第一张）:
{current_place}

画面词表（每条 = 一张能用的背景；`（…）` 里是别名；`：` 后面写的是**这张图适合演什么**
——判断靠它，不要只看名字）:
{lexicon}

编剧写的地点:
{text}

怎么选:
1. **必须从上面挑一张**——选「这场戏放在这张图里最说得通」的那个。
2. 名字对不上是**常态，不是错误**：编剧会写「杂草屋」「巷子深处」这种词表里没有的说法，
   把它对到最像的一张**就是你的活**。**读用途说明挑最像的，别因为名字不一样就放弃。**
3. 只允许一个理由说"不换"：编剧说的**就是当前这张图那个地方** → 输出 `"same"`
   （判据 = 同一个地方的不同说法，如当前是"夏莱办公室"、编剧写"老师的办公室里"）。

示范:
    当前: schale_office（夏莱办公室）
    编剧: 夜晚的模型店橱窗前
    → {"place": "shopping_district"}
       （词表里没有"模型店"这个名字，但「夜晚的商业街」最说得通：夜里的街道 + 橱窗 + 灯光。
        这种时候**对到最像的那张**，不要空着——空着画面就卡在上一张，玩家会看到地点不对。）

输出: 只输出一个 JSON 对象
- 换了地方 → {"place": "<词表里的 id>"}
- 就是当前这个地方 → {"place": "same"}
- 只输出这一个对象：不要解释、不要数组、**不要输出词表以外的 id**
