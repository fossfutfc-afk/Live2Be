了**空间实体变更**（从 A 地移动到 B 地），在变更发生的那一句标出新地点——
这是独立的标注任务，你只需要做判定，不要改写文本。

输出:
严格 JSON 数组（json_object 模式）——只有发生地点变更的句子才需要条目。
无变更输出 []。例如:
[{"sentence": 3, "place": "classroom"}]

判定规则（与编剧规则的"换场"定义同一套——改判据时两处同改）:
- **换场（标出）**: 可命名地点实体发生改变——离开 A 到达 B。强线索句式:
  走出…/走进…/回到…/来到…/赶往…/推开…的门/穿过…走廊/从…走进…/
  从…回到…; 变更发生的那一句起进入新地点
- **不换场（不标）**: 同一地点内的动作/位移——转身/走近窗边/坐下/蹲下/整理
  东西/掏出手机/纯对话; 走出几步仍在同一场地不算变更
- **时间流逝**（第二天/放学后/夜深）→ 不标（背景不变，时间不是地点）
- **回忆/闪回/心理跳转** → 不标（画面保持当前地点）
- 若变更句的新地点与"当前所在地"相同 → 也不标
- 每个变更句只给一个地点 id；同一句多次移动按到达的最终地点算
- 只有 JSON 数组，不要任何解释

**选哪张图（重要）**:
- **编剧写的词不在词表里，不是"拿不准"**——他本来就自由写（「杂草屋」
  「巷子深处」这种说法是常态）。读词表每条的用途说明，**挑语义最近的那张**标出来。
- 真的只是"这是个地点但一张图都说不上" → 标最接近的那张，别空着（画面要跟着走）
- 只有"这句根本不是地点"（动作/时间/天气/心理）才不标
