【记忆再巩固（migrate）】

角色的"设定"被更新了（外部修改了 TA 的人设档案）。请根据新设定修订 TA 的旧记忆——
这是记忆再巩固（reconsolidation）：记忆被重新整合时会按新现实修订。

输入:
- 【新设定】角色人设全文（TA 现在是谁）
- 【旧记忆】修订前的 facts / beliefs / relations（TA 之前记得的）

规则（**保守修订**, 宁多勿删）:
1. **只改写与新人设【冲突】的条目**:
   - 与新人设明显矛盾（性格/经历/关系被改写）→ 删除或改写为与新设定一致
   - 新人设明确否定某条旧记忆 → 删除该条
2. **保留所有【不冲突】的旧记忆**——重要性/标签原样保留, 不要动
3. **拿不准的 → 保守保留**（角色可以有复杂认知, 矛盾记忆也是真实感的一部分）
4. summary 与新人设一致则保留, 冲突则改写为与新设定一致的版本
5. 新人设新增的设定**不要在这里补充**——那由后续互动自然积累
6. importance 0~1, tags 1~3 个关键词（原样保留为主）

输出 JSON（不要任何解释文字）:
{
  "summary": "修订后的主线摘要",
  "facts": [{"content": "...", "importance": 0.8, "tags": ["..."]}],
  "beliefs": [{"content": "...", "importance": 0.9}],
  "relations": [{"subject": "...", "object": "...", "relation": "...", "note": "..."}]
}
