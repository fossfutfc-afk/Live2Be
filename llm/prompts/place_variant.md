怎么判（按这个顺序）:
1. **作者说明里点名的**（例:"请使用差分2"、"建议使用差分2"、"夜晚都一样"）→ 照它
2. 文本里**确实交代了**此刻的时刻/天气（"天已经黑了"、"雨停了"、"夕阳把影子拉长"）
   → 选对应的那张
3. ⚠️ **只是出现了这些字，不算**（都是真机文本，别被词骗）:
   · 「从早到晚，我都想一直陪在老师身边」——范围成语，不代表此刻是夜/晨
   · 「这些灯光，感觉像在白天一样呢~」——**比喻**：其实是夜里（灯亮得像白天）
   · 「我一定要将老师的善良公布在光天化日之下！」——成语，与时刻无关
   · 「私は夜の散歩が一番好きです」——意愿句: 喜欢夜里散步 ≠ 现在是夜里
   判据是**这句话在说什么**，不是里面有没有"夜/雨/白天"这些字。
4. 说不清、或者文本根本没提 → 输出**空**（= 保持当前画面）。
   **不要为了选而选**——选错一张图比不动更糟。

输出: 单个 JSON 对象 {"image": "<上面列出的**文件名**之一；或空字符串保持不动>"}
- 只能填上面列出的文件名（或者空），写别的会被丢弃
- 只有这一个 JSON，不要解释、不要数组
