# llm/ — 传输层

**作用**：与模型服务打交道的那一层——怎么发、发几次、用哪个档位、图怎么出。
它只认 `contract/` 与 `infra/`，**不 import `core/`**（2026-10-15 起零依赖）。

## 核心文件

| 文件 | 是什么 |
|---|---|
| `client.py` | 客户端：配置优先级（构造参数 > settings.toml > .env > 默认）、超时 / 流式 / usage 日志、反馈重试、`llm_chat` |
| `retry.py` | "发一次 → parse → 被拒就把原文 + 引擎错误回灌 → 重试"这一个循环，bond / mmt / digest 共用 |
| `task_labels.py` | 「这次调用是谁」的唯一真源（label → task 标签）；测试桩按它认任务，不再按 prompt 中文关键字 |
| `task_levels.py` | 档位真源：每个形态的 thinking 档与 max_tokens（`[llm.tasks.*]` 可覆盖） |
| `image_gen.py` | 生图（纪念立绘）：参考图收集、画幅 / 构图 / 负向尾段、gallery 记账 |
| `prompts/` | 提示词文案仓库（rules / task 卡 / 各标注 prompt），人可改 |

## 两条纪律

1. 文案住在 `prompts/*.md`，代码只加载。改完要刷夹具再人工审 diff：
   `$env:PROMPTKIT_UPDATE_FIXTURES=1; pytest tests/core/test_promptkit_baseline.py`。
2. 档位、超时、重试的默认值集中在 `task_levels.py` 与 `client.py`，别在引擎里再写一份。
