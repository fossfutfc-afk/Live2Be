# tui/ — 终端表现层

**作用**：把"要演什么"变成**终端上看得见的东西**（背景标签、立绘差分、特效符号、打字机、选项）。
只出意图与执行意图，不判剧情——剧情判定在 `core/`。

## 核心文件

| 文件 | 是什么 |
|---|---|
| `renderer.py` | 渲染管线主类 `Renderer` / `RenderOutput`（原来的 `core.py`） |
| `scene.py` · `state.py` | `RenderScene`（一场的输入）· `RenderState`（累积状态） |
| `background.py` · `sprite.py` · `effects.py` · `audio.py` | 四种解析器：背景 / 立绘差分 / 特效符号 / 音频请求 |
| `cli.py` | 终端输出（打字 / 标签 / 选项）；`PARA_CHAR_MS` 在这里 |

## 两条纪律

1. **只依赖 `core/`**：不许 import `webgui/` / `cli/`（`tests/core/test_import_direction.py` 钉着）。
   注意 `core/` **也不许** import 本包——那边需要的是"展示数据"（`core/display.py`），不是终端渲染。
2. 特效名（`sparkle` / `heart` …）的真源在后端 `effects.py`，**网页那份符号表**（`webgui/static/js/bond.js`
   的 `FX_SYMBOLS`）必须与之对齐，由 `tests/webgui/test_frontend_contract.py` 钉住。
