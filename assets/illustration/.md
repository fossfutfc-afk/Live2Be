# resources/illustration/ — 角色立绘素材库

按角色目录组织：`resources/illustration/{char_id}/`

## 目录结构

| 子目录 | 内容 | 说明 |
|--------|------|------|
| `diff/` | 静态差分 PNG（如 `haruka_spr_00.png`、`Eye_Close`、`Idle`） | 可直接展示的表情/姿态差分 |
| `spine/` | **Spine 骨骼动画**（`.skel` 骨骼 + `.atlas` 图集 + `.png` 贴图） | 由 `tools/fetch_kivo.py` 从 kivo.wiki 下载；**需 Spine 播放器渲染**（如 pixi.js-spine），本仓库只入库不渲染 |
| `possession/` | 角色物品图（如 `haruka_chocolate.png`） | 剧情/聊天中可引用的道具图片 |
| `l2d/` | 空（占位） | 规划中：L2D 生成立绘存放处（纪念画廊） |
| `other/` | 空（占位） | 其他杂项素材 |

## 命名约定

- 静态差分：`{char_id}_spr_{编号}.png`，特殊态用 `_Eye_Close_01` / `_Idle_01` 等后缀
- Spine 资源：目录名 = 差分集名（`haruka_spr` / `haruka_spr_HD` / `haruka_spr_Steam` / `Haruka_home`）

## 与代码的关系

- MMT 动作 `mmt_send_media` 的 `library_id` 概念上引用这里的素材（"先查资源库, 库里没有现成图再按描述生成"）——**媒体管线尚未接入**，当前仅占位
- 背景素材在 `resources/background/`（当前为空，需另找来源）
