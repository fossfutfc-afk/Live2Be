# infra/ — 底座

**作用**：全项目共用的"环境事实"——路径住哪、配置怎么读、文件怎么原子地写、两轴怎么融合。
它**不含业务判断**，只被依赖，不依赖 `contract/` 之外的东西（`llm → core` 必须保持零依赖，
横切件因此都住这儿）。

## 核心文件

| 文件 | 是什么 |
|---|---|
| `paths.py` | 固定路径的唯一清单（宏形态，全部平铺在顶层）：五个根 `RESOURCE`（只读，随包）/ `CONFIG` / `ASSETS` / `APP` / `DATA`，以及派生的 25 个常量 |
| `settings.py` | `settings.toml` 的**唯一读写口**：读 `raw()` / `section(name)`；写 `write()`（整文件）/ `update(section, **kv)`（只改几个键，空串 = 删键） |
| `logsetup.py` | 双 handler 日志：控制台短（轮询/静态 2xx 不打印）、`data/diag/live2be.log` 全量；`LIVE2BE_LOG=quiet\|normal\|verbose` |
| `runtime.py` | 关停信号 + 在途任务台账（digest 在轮次间/提交前看它；关停时等它收手） |
| `shell.py` | OS 小动作：提权判定、降权启动（`runas /trustlevel:0x20000`）、打开资源管理器 —— 住这儿是为了让 `setup_tool` 不必拖进 fastapi |
| `packs.py` | 素材包：清单解析 / "装没装"判定 / 下载 + sha256 + 解压（只有 stdlib，HTTP 走 `urllib`） |
| `atomic.py` | 原子替换的 Windows 健壮性包装：`os.replace` + 占用短重试（`replace_with_retry`） |
| `fuse.py` | 两轴融合的**唯一形状**（调和平均）：召回侧与解析侧各注入轴的含义，共用同一份算术 |

## 四条纪律

1. **不许在函数体里现拼项目根路径**：一律在 `paths.py` 顶层写常量，消费方写
   `from infra import paths` + `paths.NAME`（便于 grep）。守门 = `tests/core/test_paths.py`
   （扫七个源码包，含多行别名写法）。
2. **可写根与只读根分开**：往 `RESOURCE_ROOT` 写在打包后**不报错、退出即丢**，
   所以写调用的目标由静态判据挡住（同一份守门测试）。
3. **`settings` 不缓存、每次重读**：同长度的改写会落在同一个 mtime 刻度里，
   mtime+size 那次缓存读到过旧值（自己的测试抓到的洞）。别再加回来。
4. **`[paths]` 是 import 期常量**：`paths.py` 在 import 时读 settings.toml 的 `[paths]`，
   而且消费方会把它存成自己的常量（`CHAR_ROOT = paths.CHARACTERS_DIR`）——**改完要重启**。
