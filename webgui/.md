# webgui/ — 网页界面（FastAPI 壳 + 前端）

**作用**：把引擎接到浏览器上。后端只做翻译——HTTP 请求驱动 `core/` 引擎，引擎状态翻成
板载荷；判定逻辑不写在这里。前端**无构建步骤**：`index.html` 直接引 classic script，
浏览器看到的目录就是本包的 `static/`。

## 后端

| 文件 / 目录 | 管什么 |
|---|---|
| `app.py` | 薄壳：建 FastAPI · 挂 4 个静态目录 · 注册 9 个 router · 日志与关停接缝（`logsetup` / `runtime`） |
| `serve.py` | **启动入口**（`python -m webgui.serve`）：自持 `uvicorn.Server`，**忽略 Ctrl+C**；关停由前端发起 |
| `shutdown.py` | 关停口令（`/api/menu` 下发）+ 本机来源校验 —— `POST /api/shutdown` 的守门 |
| `deps.py` | **显式接缝**：store · 生图器 · 标注钩子 · 三个看门狗阈值 · choice 开关 |
| `chat.py` | MMT 域：每角色一个引擎实例 + 同角色串行锁 · 后台线程跑 `agent_turn` · 会话 resume / 新开 |
| `store.py` | GUI 设置页读写 settings.toml（`DEFAULTS` 兜底 + 手写序列化） |
| `bond/` | 羁绊剧情状态机（模块分工见 `bond/__init__.py` 那张表）：`state` · `stores` · `lanes` · `replay` · `memorial` · `pregen` · `watchdog` · `entry` · `api` · `util` |
| `routers/` | HTTP 路由按域分文件：`name` 登录彩蛋 · `settings` · `menu` 页面背景 · `mmt` · `bond` · `collection` · `spine` · `runtime`（状态快照 + 关停） |

前后端约定：**没有 SSE**（未立项）——前端轮询 `bond_status` / `events_after`。

## 关停（唯一常规出口是前端）

`Ctrl+C` 在 `serve.py` 里被**忽略**（只打一行提示）——手滑打断记忆消化太贵。退出走菜单里的
「关闭服务」：

| 端点 | 语义 |
|---|---|
| `GET /api/runtime/status` | `runtime.snapshot()`：`{"shutdown", "busy":[{"name","stage","elapsed_s"}]}` |
| `GET /api/runtime/paths` | 五个根 + settings 路径（设置页显示"东西都在哪"） |
| `POST /api/runtime/open` | `{"which":"data"\|"assets"\|"config"\|"app","token":…}` —— 在资源管理器里打开（**只认这四个根，不许传任意路径**） |
| `POST /api/shutdown` | `{"mode":"graceful"\|"force", "token":…}`；graceful 等长任务收手（≤180s）再退，force 立刻退 |

两条纪律：① **口令 + 本机来源**双校验（否则任意网页都能关掉你的服务 / 在你机器上弹窗口）；
② 关停端点只对 `python -m webgui.serve` 起的进程有效（自持 server 才关得动），否则回 409 ——
**宁可如实说"关不掉", 不许显示"正在关停"却不停**。强杀（关窗口 / 任务管理器）也是安全的：
wiki 提交是两阶段的（`core/brain/store.commit`），digest 在提交前看关停信号。

⚠️ **提权时开浏览器/资源管理器要走 `explorer.exe`**（`serve.open_browser` / `open_folder` 已做）：
直接 `os.startfile` 会让 Edge 继承管理员令牌，它弹"要不要用普通权限"并重启自己，标签页就没了。

## 前端（`static/`）

装载顺序（`index.html`）：`typing.js` → `gui.js` → `main.js` → `settings.js` → `mmt.js`
→ `collection.js` → `bond.js`（唯一 module，排最后）。`typing.js` 是打字节奏的**唯一实现**
（`window.L2BTyping`），`bond.js` / `mmt.js` 只调它。`vendor/` 里是 pixi 与字体，不动。

## 纪律

1. **没人可以 import 它**：`contract/` `infra/` `llm/` `core/` `tui/` `cli/` 都不许依赖本包
   （`tests/core/test_import_direction.py` 钉着）。
2. **可替换依赖一律走 `deps.py`**：包内子模块读的是自己的全局，`monkeypatch.setattr(webgui.bond, …)`
   会**静默失效**（测试照旧绿、覆盖全丢）⇒ 消费方写 `deps.xxx`（调用时属性查找），测试 patch `deps.xxx`。
3. **`bond/__init__.py` 只做再导出**：不放逻辑、不定义 `__all__`；名字增删同步
   `tests/fixtures/api_surface.txt`（`SPLIT_API_UPDATE=1` 刷新）。
4. **两个等待阈值不是一条规则**，别合并：`GATE_DISPLAY_WAIT_MS` 只决定前端等不等
   （到点 `gate_busy` 转 false，一个字节的数据都不改）· `GATE_WATCHDOG_MS` 是管线安全
   （会把兜底 emotion 写进 append-only 真源）。
5. 改前端：`node --check <file>` 兜底语法；纯逻辑单测 `node --test tests/webgui/js/typing.test.js`
   （传文件，别传目录）；特效名两边对齐由 `tests/webgui/test_frontend_contract.py` 守。
