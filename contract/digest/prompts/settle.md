    {"entities": [ // 没有要动的、也没有要建的, 就写 [] //
        {"name": "阿露", "aliases": ["aru"], "reason": "她这一段来了三次, 以后还会来",
         "text": "她是把我从霸凌里带出去的人"},                 // 没有 id ⇒ **建一个新的** //
        {"id": "x0001", "text": "老师是第一个不会嫌弃我的人"},   // 有 id ⇒ **改已有的** //
        {"id": "x0004", "name": "小玉"}                        // 有 id ⇒ 只改名 //
    ]}

一行 = 一个**长期对象**（人 / 地方 / 东西）—— **`id` 决定这一行是"建"还是"改"**:

ⓐ **没有 `id`** ⇒ **建一个新的**（号由引擎发）:
  name    —— 名字, 或**她叫它的那个说法**（必填; 照【她写了、但库里还没有的名字】里那样写;
            ≤8 字 —— 更长的不是称呼, 是一句话; ⭐ 只有印象、还不知道真名 ⇒ 用她真会用的
            短叫法（"那个女生"）—— 以后知道真名了, 再用有 `id` 的那一行改）;
  reason  —— **为什么给它一个永久位置**（必填; 一句话 —— 建对象是永久成本）;
  aliases —— 可选; 别的叫法（同一个人的其它称呼; 最多 8 个）;
  text    —— 可选; 她此刻对它的看法（**一句话 ≤60 字**, **第一人称**）——
            ⭐ **刚认识就有话说, 就在这一行里顺手写上**（不用等下一段）。

ⓑ **有 `id`** ⇒ **改一个已经认识的对象**（编号照抄【这一段认下的对象】）:
  name    —— 可选; **她后来知道了它本来叫什么** ⇒ 写这里（≤8 字）—— 旧的叫法
            **自动降级成别名**（两个叫法从此都指它）;
            ⭐ **只有这一段的事撑得住"就是同一个人"时才写**; ⛔ 只是像 / 只是同一个头衔 /
            同一类人 ⇒ 别写（写错会把两个人并成一个, 再也分不开）;
  text    —— 可选; 她此刻对它的看法（写法同 ⓐ; ⚠️ **整段重写** —— 见下面那条规则）;
  ⚠️ **`name` 与 `text` 至少给一个**（给哪个改哪个）;
  ⛔ 这一路**不写 `reason`**（"为什么值得记"是建对象时才要回答的）、**不写 `aliases`**。

规则:
  · ⭐ **不该占位置的一条都别写**: NPC · 店员 · 路人 · 只出现一次的相遇 ·
    以后多半不会再遇到的 —— 都不写; ⛔ 也别为了清空名单而写;
  · ⛔ **不许编**: 没 `id` 那一行的 `name` 必须是【她写了、但库里还没有的名字】里的;
    有 `id` 那一行的编号必须是【这一段认下的对象】里的 —— 编的会被**丢掉**;
  · ⭐ **没把握就不写** —— `[]` 是合法答案;
  · ⛔ **不改名字与看法之外的东西、不连边**: 归属边由引擎按引用自己连;
  · ⭐ **看法 ≠ 结论**: 「我心里渐渐觉得」那一栏是**一条结论**（有证据边、会被推翻）;
    这一栏是**她对这个对象整个人的几句话**
  · ⭐ **写 `text` 就是整段重写**: 新写的会**替掉**旧的那句 ⇒ 只要旧句说的东西没被推翻，就需要包含那些情况
    ，不过可以更改表述，可以为了压字数缩略; 这一段没让她改观 ⇒ **别写这个格**;
  · ⚠️ **`（还没写过）` 不是错**: 那只是"她还没想过这个人", 不写完全合法, 不了解的角色，可以直接在里面写自己了解不足。
